# 🎵 Discord Music Bot

بوت ديسكورد احترافي لتشغيل أغاني يوتيوب مع تحكم كامل.

## المميزات
- تشغيل أغاني يوتيوب بجودة عالية
- إيمبدات احترافية مع صور
- قائمة تشغيل (Queue)
- تحكم: تخطي، إيقاف، إيقاف مؤقت، استئناف
- التحكم بمستوى الصوت
- تكرار الأغنية
- بحث واختيار من نتائج متعددة

## المتطلبات
- Python 3.10+
- FFmpeg (مثبت ومضاف إلى PATH)

## التثبيت
```bash
pip install -r requirements.txt
```

## التشغيل
1. انسخ `.env.example` إلى `.env`
2. ضع توكن البوت في `.env`
3. شغل البوت:
```bash
python main.py
```

## الأوامر
| الأمر | الوظيفة |
|-------|---------|
| `!play <اسم/رابط>` | تشغيل أغنية |
| `!skip` | تخطي الأغنية |
| `!stop` | إيقاف وإخراج البوت |
| `!pause` | إيقاف مؤقت |
| `!resume` | استئناف |
| `!queue` | عرض قائمة التشغيل |
| `!nowplaying` | الأغنية الحالية |
| `!volume <0-100>` | التحكم بالصوت |
| `!loop` | تشغيل/إيقاف التكرار |
| `!help` | عرض الأوامر |
